CHAPTER 02Part I · Architecture

State Space Models & Mamba

The most credible attempt to replace attention with a linear-cost recurrence. We walk from HiPPO through Mamba-2 and into the hybrids that actually ship in 2026.

2020 HiPPO · S4 2022 S4 scaled 2023-12 Mamba (Gu & Dao) 2024-03 Jamba (AI21) 2024-05 Mamba-2 · SSD 2024-06 Samba (Microsoft) 2024-02 Griffin / RecurrentGemma 2025-2026 hybrid is default
🧒 ELI5 — explain like I'm five

Imagine reading a book. A transformer is a reader who, before saying the next word, re-reads every single word they've ever seen. That's very thorough, but it gets slower and slower the longer the book is.

A Mamba / state space model is a reader who keeps a small notebook. After every sentence they update their notebook with what mattered, then throw the sentence away. To predict the next word they only look at the notebook. That's much faster — the book can be a million pages and it still takes constant effort per sentence.

The catch: if the notebook is too small, they forget details. Mamba's trick is that the notebook knows what to remember based on what it's reading (that's the "selective" in "selective SSM"). Modern architectures combine both — a transformer reads recent pages carefully and a Mamba remembers the rest.

2.1 Where SSMs Come From

State-space models come from control theory. A continuous-time linear dynamical system is:

$$h'(t) = A\,h(t) + B\,x(t), \qquad y(t) = C\,h(t) + D\,x(t)$$

An input signal x(t) drives a hidden state h(t) of fixed dimension N; the output y(t) is a linear readout. Discretise in time with step Δ and you get:

$$h_k = \bar A\, h_{k-1} + \bar B\, x_k, \qquad y_k = C\, h_k$$

This looks like an RNN and is. The S4 line (Gu et al. 2021–2022) showed you can initialise A using HiPPO theory and get strong long-range modelling — but the transitions are input-independent, so the model can't selectively remember or forget based on the content.

2.2 The Selective Mechanism — Mamba's Key Move

Mamba (Gu & Dao, Dec 2023) makes A, B, and Δ functions of the input. That is, at every position k:

$$B_k = \text{Linear}_B(x_k),\ C_k = \text{Linear}_C(x_k),\ \Delta_k = \text{softplus}(\text{Linear}_\Delta(x_k))$$

The resulting recurrence is selective: for each token the model decides how much of the past to keep, how much of the current input to incorporate, and how to read it out. This closed the "information loss" gap that killed pure S4 on language modelling.

An SSM is an RNN and a causal 1D convolution at the same time. That's the engineering win: train parallelly, generate cheaply.

2.3 Recurrence ⇄ Convolution & the Parallel Scan

Because the recurrence is linear, unrolling it exposes a convolution against a structured kernel. At training time you run a parallel scan (work-efficient prefix sum) instead of a sequential RNN loop. At inference time you run it as an RNN with O(1) memory per token.

This is what makes Mamba shipable: you pay the favourable cost at each phase.

2.4 Mamba-2 and State-Space Duality

Dao & Gu's follow-up (May 2024) made a surprising observation: any SSM with diagonal transitions can be expressed as an attention variant (a "linear-attention" with a specific mask). This is state-space duality (SSD). Two practical consequences:

  • Mamba-2 blocks can be written as structured attention, so they inherit GPU optimisation work from the transformer ecosystem.
  • Hybrid blocks (attention + Mamba in the same stack) have a unifying framework rather than being ad-hoc glue.

The converging empirical story: small amounts of attention (often just one block per handful) are load-bearing for in-context learning. The rest of the stack can be Mamba-style and get you the long-context + throughput wins.

2.6 When SSMs Win — and When They Don't

Where SSMs clearly win

Long-sequence ingestion (DNA, audio, 1M-token documents), edge / on-device inference with tight memory, workloads where KV cache dominates VRAM.

— Mamba-2, Samba, Codestral-Mamba (2024)

Where they don't (yet)

Pure SSMs underperform on ICL-heavy tasks — few-shot reasoning, retrieval from context, chain-of-thought math. The fix is hybrids. Pure SSM at frontier scale for chat has not yet shipped.

— benchmark consensus, ICLR 2025 / 2026

2.7 Reference — Selective SSM Block (abridged)

import torch, torch.nn as nn, torch.nn.functional as F

class SelectiveSSM(nn.Module):
    def __init__(self, d_model, d_state=16):
        super().__init__()
        self.d, self.N = d_model, d_state
        self.A_log = nn.Parameter(torch.log(torch.arange(1, d_state + 1).float()).expand(d_model, -1).clone())
        self.D     = nn.Parameter(torch.ones(d_model))
        self.proj  = nn.Linear(d_model, d_state * 2 + 1)   # B, C, Δ per-token

    def forward(self, x):                                 # x: (B, L, d)
        B, L, D = x.shape
        A = -torch.exp(self.A_log)                        # (d, N), negative real → stable
        Bt, Ct, dt = self.proj(x).split([self.N, self.N, 1], dim=-1)
        dt = F.softplus(dt)                               # (B, L, 1)

        # discretise
        Ad = torch.exp(A.unsqueeze(0).unsqueeze(0) * dt.unsqueeze(-1))         # (B, L, d, N)
        Bd = (dt.unsqueeze(-1) * Bt.unsqueeze(-2))                             # (B, L, d, N)

        # parallel scan (stand-in; real Mamba uses the fused kernel)
        h = torch.zeros(B, D, self.N, device=x.device)
        ys = []
        for k in range(L):
            h = Ad[:, k] * h + Bd[:, k] * x[:, k].unsqueeze(-1)
            ys.append((h * Ct[:, k].unsqueeze(-2)).sum(-1))
        y = torch.stack(ys, dim=1) + self.D * x
        return y

The reference implementation at github.com/state-spaces/mamba has a hand-written CUDA kernel for the scan that's ~50× faster than this Python loop. That kernel is why Mamba is shipable.

❓ Open questions

  • Is there an SSM-native in-context-learning mechanism, or will attention always do that job in hybrids?
  • Do Mamba-class models get better with scale at the same rate as transformers? (Early evidence: yes, with caveats.)
  • Is SSD the deepest framework for unifying SSM and attention, or is there a more general picture coming?
