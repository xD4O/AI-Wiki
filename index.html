How to Use This Wiki

📖 Read in order

Chapters build on each other. If you're new, start at Chapter 1 and work through sequentially.

💻 Run the code

Every major concept has a runnable Python example using NumPy, PyTorch, or Hugging Face.

🎨 Study diagrams

Visual intuition matters. All diagrams are professionally drawn — study them as deeply as the prose.

Prerequisites

You should be comfortable with high-school math and basic Python. Chapter 2 covers the math you need. No prior ML knowledge required.

Continue to Volume II

Volume I ends with the frontier of how models are made. Volume II — The Agentic Frontier — picks up from there: local deployment, prompting, context engineering, RAG, skills, MCP, agent architectures, interpretability, and production.
