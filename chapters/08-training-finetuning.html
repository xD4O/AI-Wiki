8.1 The Modern Training Pipeline

A production-quality model today passes through four stages. Each uses different data, different objectives, and different compute budgets.

Four stages — each smaller, more curated, and more targeted than the last.

8.2 Supervised Fine-Tuning (SFT)

SFT teaches the base model to follow instructions. The data is a set of (prompt, response) pairs written or filtered by humans. The training objective is still next-token prediction — only on the response part.

from transformers import AutoTokenizer, AutoModelForCausalLM, Trainer, TrainingArguments
from datasets import load_dataset

model_id = "meta-llama/Llama-3-8B"
tok = AutoTokenizer.from_pretrained(model_id)
model = AutoModelForCausalLM.from_pretrained(model_id, torch_dtype="auto")

ds = load_dataset("tatsu-lab/alpaca")                 # classic SFT dataset

def format_example(ex):
    prompt = f"### Instruction:\n{ex['instruction']}\n\n### Response:\n"
    full   = prompt + ex["output"]
    ids    = tok(full, truncation=True, max_length=1024, padding="max_length")
    # Mask loss on the prompt (only train on response)
    prompt_len = len(tok(prompt)["input_ids"])
    labels = ids["input_ids"].copy()
    labels[:prompt_len] = [-100] * prompt_len
    ids["labels"] = labels
    return ids

ds = ds.map(format_example)
trainer = Trainer(
    model=model,
    train_dataset=ds["train"],
    args=TrainingArguments(
        output_dir="sft-llama",
        per_device_train_batch_size=1,
        gradient_accumulation_steps=16,
        learning_rate=2e-5,
        num_train_epochs=3,
        bf16=True,
    ),
)
trainer.train()

8.3 Parameter-Efficient Fine-Tuning (PEFT)

Full fine-tuning of a 70B model requires ~1 TB of GPU memory — out of reach for most people. PEFT methods freeze the base model and only train a tiny set of new parameters (often <1%). Quality matches full FT; cost is 100×+ lower.

LoRA

Add low-rank "delta" matrices to attention weights. Train only those. Standard for instruction tuning open models.

QLoRA

LoRA applied on top of a 4-bit quantized base model. Fine-tune a 70B on a single 48 GB GPU.

Prefix / Prompt tuning

Prepend trainable "virtual tokens" to the input. Cheapest of all, but less expressive than LoRA.

8.4 LoRA in Depth

For a weight matrix $W \in \mathbb{R}^{d \times k}$, LoRA learns $W' = W + \Delta W$ where $\Delta W = B A$ with $A \in \mathbb{R}^{r \times k}$, $B \in \mathbb{R}^{d \times r}$ and $r \ll \min(d, k)$.

LoRA — only the two small matrices A and B are trained. The huge W is frozen. 
from peft import LoraConfig, get_peft_model, TaskType
from transformers import AutoModelForCausalLM

base = AutoModelForCausalLM.from_pretrained("meta-llama/Llama-3-8B", load_in_4bit=True)

lora_config = LoraConfig(
    task_type=TaskType.CAUSAL_LM,
    r=16,
    lora_alpha=32,
    lora_dropout=0.05,
    target_modules=["q_proj", "k_proj", "v_proj", "o_proj"],  # which weights to adapt
)

model = get_peft_model(base, lora_config)
model.print_trainable_parameters()
# trainable params: 41M || all params: 8.0B || trainable%: 0.5%

8.5 Quantization

Models are trained in 16- or 32-bit floats. For inference, we can compress to 8-bit (int8), 4-bit (NF4), or even lower — with minimal quality loss.

8.6 Distillation

Knowledge distillation trains a small "student" model to match the output distribution of a larger "teacher." The student learns not just "the right answer" but the teacher's full probability distribution — which encodes uncertainty and similar-but-wrong alternatives.

$$ L_{\text{distill}} = (1 - \alpha) \cdot L_{\text{CE}}(y, \hat{y}_{\text{student}}) + \alpha \cdot T^2 \cdot D_{\text{KL}}\!\left(p_{\text{teacher}}^T \,\|\, p_{\text{student}}^T\right) $$

Distillation is why Claude Haiku, GPT-4 Turbo, and Gemini Flash exist: most of the capability of their bigger siblings, at a fraction of the cost.

8.7 A Practical Recipe

If you want to adapt an open LLM to your domain (customer support, medical coding, code review, whatever), this is the 2026 default recipe:

  1. Pick a base model (Llama-3-8B, Mistral-7B, or similar).
  2. Collect ~1k – 10k high-quality (prompt, ideal_response) pairs for your task.
  3. Load the base in 4-bit (bitsandbytes), apply QLoRA with r=16, α=32.
  4. Train 3 epochs at lr=2e-4 on a single 24-80 GB GPU.
  5. Evaluate on held-out prompts; compare with automated metrics + human ratings.
  6. If needed, add DPO with preference pairs for safety & style (Chapter 9).
  7. Merge LoRA weights back into the base and quantize to GGUF/AWQ for serving.
Data quality beats quantity

1k carefully curated examples almost always beat 100k scraped ones. Instruction fine-tuning data quality is the single biggest knob on final model quality. Spend time on your dataset.
