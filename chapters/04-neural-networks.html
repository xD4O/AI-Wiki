CHAPTER 04 Deep Learning

Neural Networks

From a single neuron to a deep network, and how backpropagation lets us train billions of parameters at once.

In this chapter

4.1 The Artificial Neuron

A neuron takes several inputs, multiplies each by a weight, sums, adds a bias, and applies a non-linear activation function.

$$ a = \sigma\!\left(\sum_{i=1}^n w_i x_i + b\right) = \sigma(\mathbf{w}^\top\mathbf{x} + b) $$
A single artificial neuron: weighted sum, bias, non-linearity.

4.2 Multi-Layer Perceptrons

Stack neurons into layers. The output of each layer feeds the next. A Multi-Layer Perceptron (MLP) with at least one hidden layer is a universal approximator — given enough neurons, it can approximate any continuous function.

A 4-6-6-3 MLP — every neuron in one layer connects to every neuron in the next.

4.3 Activation Functions

Without non-linearity, a deep network collapses to a linear model. The activation function is what lets depth help.

ReLU dominates modern nets; GELU is standard in transformers; sigmoid/tanh are mostly historical.

4.4 The Forward Pass

A forward pass is just a sequence of matrix multiplies and activations:

$$ \mathbf{h}^{(1)} = \sigma(\mathbf{W}^{(1)} \mathbf{x} + \mathbf{b}^{(1)}) $$ $$ \mathbf{h}^{(2)} = \sigma(\mathbf{W}^{(2)} \mathbf{h}^{(1)} + \mathbf{b}^{(2)}) $$ $$ \hat{\mathbf{y}} = \mathbf{W}^{(3)} \mathbf{h}^{(2)} + \mathbf{b}^{(3)} $$

4.5 Backpropagation

Backprop is the chain rule applied to the forward pass. After computing the loss $L$, we push gradients backward layer by layer:

Forward: compute activations. Backward: compute gradients of the loss w.r.t. every parameter.

For each parameter $\theta$, backprop gives us $\frac{\partial L}{\partial \theta}$. Then gradient descent updates: $\theta \leftarrow \theta - \eta \frac{\partial L}{\partial \theta}$.

4.6 A Network from Scratch

A 2-layer MLP for MNIST-like digit classification — implemented with only NumPy. Every line corresponds to equations above.

import numpy as np

class MLP:
    def __init__(self, in_dim, hid_dim, out_dim, lr=0.05):
        # Kaiming-ish init to keep signal stable
        self.W1 = np.random.randn(in_dim, hid_dim) * np.sqrt(2.0 / in_dim)
        self.b1 = np.zeros(hid_dim)
        self.W2 = np.random.randn(hid_dim, out_dim) * np.sqrt(2.0 / hid_dim)
        self.b2 = np.zeros(out_dim)
        self.lr = lr

    @staticmethod
    def relu(x): return np.maximum(0, x)

    @staticmethod
    def softmax(z):
        z = z - z.max(axis=1, keepdims=True)
        e = np.exp(z); return e / e.sum(axis=1, keepdims=True)

    def forward(self, X):
        self.X = X
        self.z1 = X @ self.W1 + self.b1
        self.a1 = self.relu(self.z1)
        self.z2 = self.a1 @ self.W2 + self.b2
        self.p  = self.softmax(self.z2)
        return self.p

    def backward(self, y):
        # y is one-hot; cross-entropy w/ softmax has clean gradient
        n = y.shape[0]
        dz2 = (self.p - y) / n                      # (n, out)
        dW2 = self.a1.T @ dz2                       # (hid, out)
        db2 = dz2.sum(axis=0)

        da1 = dz2 @ self.W2.T                       # (n, hid)
        dz1 = da1 * (self.z1 > 0)                   # ReLU derivative
        dW1 = self.X.T @ dz1
        db1 = dz1.sum(axis=0)

        self.W1 -= self.lr * dW1;  self.b1 -= self.lr * db1
        self.W2 -= self.lr * dW2;  self.b2 -= self.lr * db2

    def loss(self, y):
        return -np.mean(np.sum(y * np.log(self.p + 1e-12), axis=1))


# ---- tiny synthetic demo: 3 clusters of 2D points ----
rng = np.random.default_rng(0)
centers = np.array([[2,2], [-2,2], [0,-2]])
X = np.vstack([rng.normal(c, 0.6, (100, 2)) for c in centers])
y_int = np.repeat(np.arange(3), 100)
y = np.eye(3)[y_int]                                  # one-hot

net = MLP(2, 16, 3, lr=0.1)
for step in range(1000):
    net.forward(X); net.backward(y)
    if step % 200 == 0:
        acc = (net.p.argmax(1) == y_int).mean()
        print(f"step {step:4d}   loss {net.loss(y):.3f}   acc {acc:.3f}")
You've built deep learning

Every modern architecture — CNNs, transformers, diffusion models — is a variant of this pattern. The forward pass is a differentiable graph; autograd computes the gradients; gradient descent updates parameters.
