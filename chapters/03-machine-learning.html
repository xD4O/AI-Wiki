CHAPTER 03 Foundations

Machine Learning

The three flavors of learning, the workhorse algorithms, and the one trade-off that governs everything: bias vs. variance.

3.1 Three Types of Learning

All machine learning splits into three flavors based on what the system sees while learning.

Supervised learns from labels, unsupervised finds structure, reinforcement learns from reward signals.

3.2 Supervised Learning in Depth

Given training pairs $(x_i, y_i)$, find a function $f$ such that $f(x) \approx y$ on unseen data. Two flavors:

  • Regression — predict a continuous value. House prices, temperature.
  • Classification — predict a category. Spam or not, cat or dog.

Linear Regression

The simplest supervised model. Predict $\hat{y} = \mathbf{w}^\top \mathbf{x} + b$ and minimize mean squared error:

$$ L(\mathbf{w}, b) = \frac{1}{n} \sum_{i=1}^n (y_i - \hat{y}_i)^2 $$ 
import numpy as np
from sklearn.linear_model import LinearRegression

# Fake data: y = 3x + 5 + noise
rng = np.random.default_rng(42)
X = rng.uniform(0, 10, (100, 1))
y = 3 * X.squeeze() + 5 + rng.normal(0, 1.5, 100)

model = LinearRegression().fit(X, y)
print(f"slope: {model.coef_[0]:.2f}, intercept: {model.intercept_:.2f}")
# slope: 2.98, intercept: 5.11   ← recovered the true function

Logistic Regression (binary classifier)

Same linear score, but squeezed through the sigmoid and trained with cross-entropy:

$$ \hat{p} = \sigma(\mathbf{w}^\top \mathbf{x} + b) = \frac{1}{1 + e^{-(\mathbf{w}^\top \mathbf{x} + b)}} $$

Decision Trees & Random Forests

Trees split the feature space with axis-aligned rules. A random forest averages many trees trained on bootstrapped samples — a robust baseline that often beats fancier models on tabular data.

from sklearn.ensemble import RandomForestClassifier
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split

X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=0)

clf = RandomForestClassifier(n_estimators=100).fit(X_train, y_train)
print(f"accuracy: {clf.score(X_test, y_test):.3f}")  # ~0.97

3.3 Unsupervised & Self-supervised

No labels. The model's job is to find hidden structure — clusters, lower-dimensional coordinates, or underlying distributions.

  • K-means — partition data into $k$ clusters by iteratively updating centroids.
  • PCA — find the directions of greatest variance; project data onto the top few.
  • Autoencoders — a neural network that learns to compress and reconstruct its input.

Self-supervised learning is the trick that made LLMs possible: invent a label from the data itself. "Predict the next word" needs no human annotations — every text on the internet becomes training data.

3.4 Reinforcement Learning

An agent takes actions in an environment and receives rewards. The goal is to learn a policy $\pi(a \mid s)$ that maximizes expected cumulative reward.

$$ G_t = r_t + \gamma r_{t+1} + \gamma^2 r_{t+2} + \cdots = \sum_{k=0}^{\infty} \gamma^k r_{t+k} $$

Core algorithms: Q-learning, Policy Gradient, PPO. RL powered AlphaGo, and — crucially for LLMs — it's the final training stage of RLHF (Chapter 9).

3.5 Bias, Variance & Generalization

The central trade-off in all of ML. A model too simple can't fit the data (high bias → underfitting). A model too complex memorizes noise (high variance → overfitting).

The same data, three models. Underfit misses patterns; overfit memorizes noise; the middle generalizes.

Tools to fight overfitting: regularization (L1/L2), dropout, early stopping, cross-validation, and — most powerfully — more data.

3.6 An End-to-End Pipeline

A complete supervised pipeline from raw data to evaluation, in one readable file.

import numpy as np
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import classification_report, confusion_matrix

# 1. Load data
X, y = load_breast_cancer(return_X_y=True)

# 2. Train/val/test split (60/20/20)
X_tr, X_tmp, y_tr, y_tmp = train_test_split(X, y, test_size=0.4, stratify=y, random_state=0)
X_val, X_te, y_val, y_te = train_test_split(X_tmp, y_tmp, test_size=0.5, stratify=y_tmp, random_state=0)

# 3. Preprocess — fit scaler on train ONLY (avoid data leakage)
scaler = StandardScaler().fit(X_tr)
X_tr, X_val, X_te = map(scaler.transform, (X_tr, X_val, X_te))

# 4. Tune hyperparameters on val set
best_C, best_acc = None, 0
for C in [0.01, 0.1, 1, 10]:
    m = LogisticRegression(C=C, max_iter=500).fit(X_tr, y_tr)
    acc = m.score(X_val, y_val)
    if acc > best_acc:
        best_C, best_acc = C, acc

# 5. Refit with best hyperparameter, evaluate on held-out test set
model = LogisticRegression(C=best_C, max_iter=500).fit(X_tr, y_tr)
y_pred = model.predict(X_te)
print(f"best C = {best_C}, test acc = {model.score(X_te, y_te):.3f}")
print(classification_report(y_te, y_pred, target_names=["malignant", "benign"]))
Never peek at the test set

The test set simulates the real world. If you tune hyperparameters on it, you've invalidated the number. Use a separate validation set for tuning, then evaluate on test exactly once.
