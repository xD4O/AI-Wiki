CHAPTER 06 Deep Learning

NLP & Transformers

How text becomes tensors, what attention really does, and why one 2017 paper changed everything.

6.1 Tokenization

Neural networks want numbers, not strings. Tokenization breaks text into discrete units (tokens) and maps each to an integer ID.

Modern LLMs use subword tokenization — usually Byte-Pair Encoding (BPE) or SentencePiece. This keeps common words whole, splits rare words into pieces, and avoids out-of-vocabulary tokens entirely.

from transformers import AutoTokenizer

tok = AutoTokenizer.from_pretrained("gpt2")

text = "Transformers are remarkably scalable."
ids  = tok.encode(text)

print(ids)
# [15545, 11347, 389, 22585, 37727, 13]

for i in ids:
    print(f"{i:6d}  →  {tok.decode([i])!r}")
# 15545  →  'Transform'
# 11347  →  'ers'
#   389  →  ' are'
# 22585  →  ' remarkably'
# 37727  →  ' scalable'
#    13  →  '.'

6.2 Embeddings

An embedding layer is a lookup table: each token ID maps to a learned dense vector. Similar words end up with similar vectors — king ≈ queen + (male → female direction).

Embeddings place semantically similar tokens close together in vector space.

6.3 Attention — the Core Idea

Attention lets every token in a sequence look at every other token and decide which ones matter. For each token we build three vectors:

  • Query (Q) — "what am I looking for?"
  • Key (K) — "what do I contain?"
  • Value (V) — "if picked, what do I contribute?"

The scaled dot-product attention is:

$$ \text{Attention}(Q, K, V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right) V $$
Each token attends to every other token — darker squares = higher attention weights.

Multi-head attention runs the whole operation in parallel with multiple independent (Q, K, V) projection sets, so the model can attend to different kinds of relationships simultaneously (syntax, coreference, long-range dependency, etc.).

6.4 The Transformer Architecture

A transformer block combines multi-head attention with a feed-forward network, plus residual connections and layer norm.

A single transformer block. Stack 12, 24, 96, or more of these to get a modern LLM.

6.5 Positional Encoding

Attention is permutation-invariant — it doesn't know where each token sits in the sequence. We inject position information via positional encoding, either learned, sinusoidal, or (in modern LLMs) Rotary Position Embeddings (RoPE) which rotate Q and K vectors by position-dependent angles.

6.6 Attention in 20 Lines of PyTorch

import torch
import torch.nn as nn
import torch.nn.functional as F

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model=512, n_heads=8):
        super().__init__()
        assert d_model % n_heads == 0
        self.n_heads = n_heads
        self.d_k     = d_model // n_heads
        self.qkv     = nn.Linear(d_model, 3 * d_model)    # Q, K, V in one matmul
        self.out     = nn.Linear(d_model, d_model)

    def forward(self, x, mask=None):
        B, T, C = x.shape                                  # batch, seq, dim
        qkv = self.qkv(x).chunk(3, dim=-1)                 # tuple of (B,T,C)
        q, k, v = [t.view(B, T, self.n_heads, self.d_k).transpose(1, 2) for t in qkv]

        # (B, heads, T, T)
        attn = (q @ k.transpose(-2, -1)) / (self.d_k ** 0.5)
        if mask is not None:
            attn = attn.masked_fill(mask == 0, float("-inf"))
        attn = F.softmax(attn, dim=-1)

        out = attn @ v                                     # (B, heads, T, d_k)
        out = out.transpose(1, 2).contiguous().view(B, T, C)
        return self.out(out)
That's the whole secret

This 20-line block, stacked tens to hundreds of times and trained on trillions of tokens, becomes GPT, Claude, Gemini, Llama — every frontier LLM. The scale changes; the architecture barely does.
