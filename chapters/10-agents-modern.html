10.1 From Chatbot to Agent: Tool Use

A chatbot only produces text. An agent can take actions — run code, search the web, read files, send emails, edit your repository. The mechanism is simple: we teach the model to emit structured "tool call" messages in the middle of its responses, and the runtime executes them and feeds the result back.

from anthropic import Anthropic

client = Anthropic()

tools = [
    {
        "name": "run_python",
        "description": "Execute Python code and return stdout.",
        "input_schema": {
            "type": "object",
            "properties": {"code": {"type": "string"}},
            "required": ["code"],
        },
    },
    {
        "name": "web_search",
        "description": "Search the web.",
        "input_schema": {
            "type": "object",
            "properties": {"query": {"type": "string"}},
            "required": ["query"],
        },
    },
]

resp = client.messages.create(
    model="claude-opus-4-7",
    max_tokens=2048,
    tools=tools,
    messages=[{"role": "user", "content": "What's the 50th Fibonacci number?"}],
)

# resp.content may include a `tool_use` block:
# { "type": "tool_use", "name": "run_python",
#   "input": {"code": "def fib(n): ..."} }

10.2 The Agent Loop

A useful agent is just a loop: think → act → observe → think → act → … until the task is done. This is the ReAct pattern, and every modern coding agent — Claude Code, Cursor, Devin, Copilot Agent — is built on variations of it.

The agent architecture — an LLM orchestrating tools. Simple, powerful, and the backbone of all modern AI assistants.

10.3 MCP — the Model Context Protocol

In 2024 Anthropic introduced MCP, an open standard for how AI applications expose context and tools to models. Think of it as "USB for AI" — any model that speaks MCP can plug into any MCP-compliant server (databases, dev tools, enterprise systems) without bespoke integration.

MCP decouples AI apps from backend systems. Write a server once; any MCP-aware client can use it.

10.4 Reasoning Models

In 2024–2025, a new class of model emerged: reasoning models like OpenAI's o1/o3, DeepSeek R1, and Anthropic's extended-thinking Claude. These models don't answer immediately — they think silently (generate chain-of-thought) before producing a final response. Crucially, the thinking is trained with reinforcement learning against verifiable signals (does the math check out? does the code pass tests?).

Scaling laws now extend along a new axis: inference-time compute. Throw more thinking tokens at a hard problem and performance keeps improving — something classical LLMs couldn't do.

from anthropic import Anthropic
client = Anthropic()

resp = client.messages.create(
    model="claude-opus-4-7",
    max_tokens=4096,
    # Enable extended thinking: model thinks for up to 3000 tokens before answering
    thinking={"type": "enabled", "budget_tokens": 3000},
    messages=[{"role": "user", "content": "Prove that √2 is irrational."}],
)

10.5 Multimodality

Frontier models are no longer text-only. A single transformer can now ingest and generate:

Image

Vision

Images tokenized by a vision encoder feed the same transformer. GPT-4V, Claude 4, Gemini all read images natively.

Audio

Speech

Whisper-style encoders turn audio into tokens. Models like GPT-4o generate expressive speech end-to-end.

Video

Video

Gemini 2.x accepts hour-long videos as input; Sora and Veo generate minute-long video from text.

Images out

Diffusion

DALL·E, Stable Diffusion, Midjourney, FLUX. A different architecture (diffusion) than LLMs, but often orchestrated by them.

Embodied

Robotics

RT-2, VLA models — LLMs output robot actions. Early but rapidly improving.

Code

Computer use

Claude Computer Use, Operator — models that see screenshots and produce mouse/keyboard actions.

10.6 What Comes Next

Nobody knows exactly what the next five years will bring, but several directions are already visible.

FrontierWhat it means
Longer horizonsAgents that do hours or days of work autonomously, not minutes.
Verifiable reasoningInference-time compute trained via RL on tasks with checkable answers.
World modelsModels that predict the state of a physical simulation, not just next tokens.
Continual learningModels that learn and retain information from their interactions without full retraining.
Mechanistic interpretabilityUnderstanding why models output what they do — circuits, features, steering vectors.
Safe AGI?Whether and how to build systems smarter than humans while remaining aligned. Open problem.
