CHAPTER 05 Deep Learning

Deep Learning

CNNs for vision, RNNs and LSTMs for sequences, and the regularization + optimization tricks that make deep networks actually train.

5.1 Convolutional Neural Networks

MLPs don't scale to images: a 224×224×3 picture has 150,528 inputs. A convolution slides a small filter over the image and shares weights across positions — dramatically fewer parameters, and it naturally exploits spatial structure.

Convolution — slide a small kernel, take weighted sums. This kernel detects vertical edges.

A typical CNN stacks conv → activation → pool blocks to build increasingly abstract features: early layers detect edges, middle layers detect textures, late layers detect objects.

5.2 Recurrent Networks & LSTMs

Text, audio, and time series are sequences of variable length. RNNs handle this by passing a hidden state along the sequence, one timestep at a time:

$$ \mathbf{h}_t = \tanh(\mathbf{W}_x \mathbf{x}_t + \mathbf{W}_h \mathbf{h}_{t-1} + \mathbf{b}) $$
Recurrent state flows left-to-right, carrying context across the sequence.

Vanilla RNNs suffer from vanishing gradients — information decays over long sequences. LSTMs (Long Short-Term Memory) add gating mechanisms that can preserve information for thousands of steps. For over a decade, LSTMs were the default for sequence modeling — until transformers (Chapter 6) dethroned them in 2017.

5.3 Regularization

Deep networks have enough capacity to memorize any training set. Regularization techniques push them to generalize.

Dropout

Randomly zero out 10–50% of activations during training. Forces the network to build redundant representations.

Weight Decay (L2)

Add a penalty $\lambda \|\mathbf{W}\|^2$ to the loss. Encourages small weights — smoother decision surfaces.

Batch Normalization

Normalize the activations within each mini-batch. Stabilizes training and lets you use higher learning rates.

Data Augmentation

Apply random flips, crops, color jitter to training images. More data = better generalization. Free.

Early Stopping

Monitor validation loss; stop when it starts rising. Cheap and effective.

Residual Connections

Add skip paths: $\mathbf{y} = F(\mathbf{x}) + \mathbf{x}$. Enables networks with 100+ layers (ResNet).

5.4 Optimizers

Vanilla SGD works but converges slowly on deep nets. Modern optimizers adapt learning rates per-parameter and use gradient history.

OptimizerUpdate RuleWhen to use
SGD$\theta \leftarrow \theta - \eta g$Simple baselines, convex problems
SGD + Momentum$v \leftarrow \beta v + g$; $\theta \leftarrow \theta - \eta v$CNNs on vision tasks
AdamAdaptive first + second momentsDefault for most deep nets
AdamWAdam with decoupled weight decayTransformers, LLMs — the modern default

5.5 A Real CNN in PyTorch

A small ConvNet for CIFAR-10-style 32×32 images. Shows the complete modern training loop.

import torch
import torch.nn as nn
import torch.nn.functional as F

class SmallCNN(nn.Module):
    def __init__(self, num_classes=10):
        super().__init__()
        self.conv1 = nn.Conv2d(3, 32, 3, padding=1)
        self.bn1   = nn.BatchNorm2d(32)
        self.conv2 = nn.Conv2d(32, 64, 3, padding=1)
        self.bn2   = nn.BatchNorm2d(64)
        self.conv3 = nn.Conv2d(64, 128, 3, padding=1)
        self.bn3   = nn.BatchNorm2d(128)
        self.pool  = nn.MaxPool2d(2)
        self.drop  = nn.Dropout(0.3)
        self.fc1   = nn.Linear(128 * 4 * 4, 256)
        self.fc2   = nn.Linear(256, num_classes)

    def forward(self, x):
        x = self.pool(F.relu(self.bn1(self.conv1(x))))      # 32 → 16
        x = self.pool(F.relu(self.bn2(self.conv2(x))))      # 16 → 8
        x = self.pool(F.relu(self.bn3(self.conv3(x))))      # 8  → 4
        x = x.flatten(1)
        x = self.drop(F.relu(self.fc1(x)))
        return self.fc2(x)


def train_one_epoch(model, loader, optimizer, device):
    model.train()
    total, correct, loss_sum = 0, 0, 0.0
    for xb, yb in loader:
        xb, yb = xb.to(device), yb.to(device)
        optimizer.zero_grad()
        logits = model(xb)
        loss = F.cross_entropy(logits, yb)
        loss.backward()
        optimizer.step()

        loss_sum += loss.item() * yb.size(0)
        correct  += (logits.argmax(1) == yb).sum().item()
        total    += yb.size(0)
    return loss_sum / total, correct / total


device = "cuda" if torch.cuda.is_available() else "cpu"
model  = SmallCNN().to(device)
optim  = torch.optim.AdamW(model.parameters(), lr=3e-4, weight_decay=1e-4)
sched  = torch.optim.lr_scheduler.CosineAnnealingLR(optim, T_max=20)

Modern defaults

AdamW + cosine schedule + warmup + dropout + BN (or LayerNorm for transformers) is the recipe behind nearly every state-of-the-art model trained between 2018 and today.
