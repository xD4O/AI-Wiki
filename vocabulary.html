APPENDIX

Vocabulary & Definitions

Every foundational AI/ML term used in Volume I, defined compactly with a pointer to the chapter where it appears.

ABCDE FGHIL MNOP RSTU V

A

Activation function
Non-linearity applied after a linear layer. ReLU, GELU, Swish, SiLU. Ch 04
AGI
Artificial General Intelligence. A system with human-level breadth of capability. Ch 10
Agent
A system that takes actions in an environment via tools, not just text. Ch 10
Alignment
Making a model's behaviour match human intent. RLHF, CAI, DPO. Ch 09
Attention
The transformer's core operation: each token attends to every other token with learned weights. Ch 06

B

Backpropagation
The algorithm that computes gradients of a loss w.r.t. every parameter by chain rule. Ch 04
Batch normalization
Normalise activations over a mini-batch to stabilise training. Ch 05
BPE
Byte-Pair Encoding. The dominant tokenization algorithm. Ch 06

C

Chinchilla
Hoffmann et al. 2022. Compute-optimal ratio of tokens to parameters. Ch 07
Classification
Predicting a discrete label. Ch 03
CNN
Convolutional Neural Network. The workhorse for images before ViT. Ch 05
Constitutional AI
Anthropic's alignment method: replace human preference labels with a written constitution. Ch 09
Cross-entropy
The default classification loss. Negative log-likelihood under predicted class probabilities. Ch 03

D

Decoder
The half of a transformer that generates output autoregressively. Ch 06
Deep learning
Learning with many-layer neural networks. Ch 05
DPO
Direct Preference Optimization. A simpler alternative to PPO-based RLHF. Ch 09
Dropout
Randomly zero out activations during training to prevent over-fitting. Ch 05

E

Embedding
A dense real-valued vector representing a token, image, or other input. Ch 06
Encoder
The part of a transformer that maps inputs to contextual representations. Ch 06
Epoch
One full pass through the training dataset. Ch 03

F

Fine-tuning
Continuing training a pretrained model on a smaller, task-specific dataset. Ch 08
Forward pass
Computing the model's output from its input. Ch 04

G

GAN
Generative Adversarial Network. Two networks playing a min-max game. Ch 05
Gradient descent
Iteratively move parameters in the direction that reduces loss. Ch 03
GPT
Generative Pre-trained Transformer. The OpenAI model family and general architecture pattern. Ch 07

H

Hallucination
When a model confidently produces false content. Ch 07, 09
Hyperparameter
Training knob set by the user (learning rate, batch size), not by gradient descent. Ch 03

I

Instruction tuning
Fine-tuning on instruction-following examples to turn a base model into a chat model. Ch 08

L

LLM
Large Language Model. A transformer trained on text at scale. Ch 07
Linear algebra
Vectors, matrices, matrix multiplication. The lingua franca of ML. Ch 02
LoRA
Low-Rank Adaptation. Efficient fine-tuning by learning small adapter matrices. Ch 08
LSTM
Long Short-Term Memory. A gated recurrent cell, pre-transformer sequence model. Ch 05

M

Machine learning
Learning patterns from data rather than hand-coding rules. Ch 03
MCP
Model Context Protocol. Open standard for model ↔ tool integrations. Ch 10
MLP
Multi-Layer Perceptron. Stacked fully-connected layers with non-linearities. Ch 04
Multimodal
Models that process multiple modalities (text, image, audio, video). Ch 10

N

Neural network
Composition of linear layers and non-linearities, trained by backprop. Ch 04
NLP
Natural Language Processing. Ch 06

O

Optimizer
Algorithm updating weights from gradients. SGD, Adam, AdamW, Muon. Ch 05
Over-fitting
Fitting training noise; poor generalisation to new data. Ch 03

P

Perceptron
Single-layer linear classifier with a step non-linearity. The seed of neural networks. Ch 04
Positional encoding
How a transformer knows token order. Sinusoidal, learned, RoPE, ALiBi. Ch 06
PPO
Proximal Policy Optimization. The RL algorithm originally used for RLHF. Ch 09
Pretraining
The self-supervised phase that produces a base model from raw text at scale. Ch 07, 08

R

Red-teaming
Adversarial prompting / evaluation to find model failure modes. Ch 09
Regression
Predicting a continuous-valued output. Ch 03
Regularization
Techniques to prevent over-fitting: dropout, weight decay, data augmentation. Ch 05
RLHF
Reinforcement Learning from Human Feedback. The classic alignment recipe. Ch 09
RNN
Recurrent Neural Network. Earlier sequence model with hidden state. Ch 05

S

Scaling laws
Empirical power-law relationships between compute, data, parameters, and loss. Ch 07
Self-attention
Attention where queries, keys, values all come from the same sequence. Ch 06
SFT
Supervised Fine-Tuning. Fine-tuning on (prompt, response) pairs. Ch 08
Softmax
Maps a vector of logits to a probability distribution. Ch 03

T

Temperature
Sampling parameter controlling randomness during decoding. Ch 07
Token
A chunk of text produced by a tokenizer. The unit LLMs consume and produce. Ch 06
Transformer
The 2017 architecture (Vaswani et al.) that replaced RNNs. Attention + residual + MLP. Ch 06

U

Unsupervised learning
Learning from unlabelled data. Pretraining is self-supervised, a form of it. Ch 03

V

Validation set
Held-out data to tune hyperparameters, separate from train and test. Ch 03
