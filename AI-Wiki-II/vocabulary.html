APPENDIXA · Vocabulary

Vocabulary & Definitions

Every practitioner term used in Volume II, defined compactly with a pointer to the chapter where it appears.

ABCDE FGHIJ KLMNO PQRST UV

A

Agent
An LLM that takes actions in a loop — not just returns text. Spectrum from chatbot to autonomous worker. Ch 01
Agent loop
think → act → observe → repeat. The canonical pattern every agent framework implements. Ch 01, 08
Agentic retrieval
Letting the agent call a search tool mid-loop rather than doing a single retrieve-then-generate. Ch 05
ANN
Approximate Nearest Neighbor search — the algorithmic backbone of vector stores. Ch 05
AWQ
Activation-aware Weight Quantization. Fast 4-bit format for GPU inference (vLLM, TGI). Ch 02

B

BM25
Classical sparse lexical ranker. Still the non-dense half of hybrid search. Ch 05

C

Chain-of-Thought (CoT)
Prompting a model to explain its reasoning before answering. Often helps, sometimes not faithful. Ch 03
Chunking
Splitting documents into passages for RAG indexing. Fixed, sentence, semantic, or hierarchical. Ch 05
Constitutional AI
Anthropic's CAI — replace human preference labels with a written constitution the model self-critiques against. Vol I Ch 9
Context engineering
Treating the context window as a resource to design — caching, compaction, placement. Ch 04
Cross-encoder
A reranker architecture: query and passage concatenated into one model forward pass. More accurate, slower. Ch 05

D

DPO
Direct Preference Optimization. Alternative to RLHF/PPO. Vol I Ch 9

E

Embedding
A dense vector representation of text used for similarity search. Ch 05
Eval
Automated test of an LLM's output. Unit, integration, task, system levels. Ch 11

F

Few-shot
Prompting with a handful of examples before the real query. Ch 03

G

GGUF
File format from llama.cpp. The default for Ollama / LM Studio. Ch 02
GraphRAG
Build a knowledge graph from a corpus; retrieve subgraph summaries for global questions. Ch 05
Guardrails
Input filters + output validators + content classifiers wrapped around a model. Ch 11

H

Hybrid search
Combining dense (embedding) and sparse (BM25) retrieval via rank fusion. Ch 05
HyDE
Hypothetical Document Embeddings. Ask the LLM to hallucinate an answer, embed that, search with it. Ch 05

I

In-context learning
A model's ability to learn a task from examples in the prompt without weight updates. Ch 03

J

JSON mode
Model-side guarantee that output will parse as valid JSON. Ch 03

K

KV cache
Cached keys/values per past token so generation doesn't recompute attention. Dominates VRAM at long contexts. Ch 02

L

LanceDB / LangChain / LangGraph
Vector store · framework · state-machine orchestrator, respectively. Ch 05 · Ch 08
llama.cpp
C++ library for local inference. Ollama and LM Studio are wrappers around it. Ch 02
Lost in the middle
LLMs attend more to the start and end of long contexts than the middle (Liu et al. 2023). Ch 04

M

MCP
Model Context Protocol. Open standard for plugging tools/resources/prompts into any model host. Ch 07
MLX
Apple's Metal-native ML framework. Fast on M-series; LM Studio uses it by default on Mac. Ch 02
Modelfile
Ollama's per-model config: system prompt, sampling parameters, template. Ch 02
Multi-agent
Orchestrator + worker, debate, ensemble patterns. Usually worse than one good ReAct loop. Ch 09

N

NIAH
Needle-in-a-Haystack benchmark. Can the model retrieve an inserted fact from a long context? Ch 04

O

Ollama
The easiest way to run local models. Bundles llama.cpp with an OpenAI-compatible HTTP server. Ch 02
Orchestrator-worker
Multi-agent pattern. One head holds goal and state; many workers do scoped subtasks. Ch 09

P

Plan-and-Execute
Agent pattern: one planner call produces a JSON plan; cheap executor calls follow it. Ch 08
Prompt caching
Reuse KV-cache for repeated prompt prefixes; 5-10× cheaper/faster on cache hits. Ch 04

Q

Q4_K_M / Q8
GGUF quantization levels. Q4_K_M is the default sweet spot; Q8 for minimal quality loss. Ch 02

R

RAG
Retrieval-Augmented Generation. Query → embed → search → rerank → compose → generate. Ch 05
RAGAS
Open-source RAG evaluation framework. Faithfulness, answer relevance, context precision. Ch 05
ReAct
Reason-Act-Observe loop (Yao 2022). The default agent pattern. Ch 01, 08
Reflexion
Agent pattern. After failure, write a reflection, store in episodic memory, retry. Ch 08
Reranker
Second-stage cross-encoder that reorders top-N candidates from first-stage retrieval. Ch 05
Router agent
A small classifier that dispatches to specialised downstream pipelines. Ch 08

S

SAE
Sparse Autoencoder. Decomposes dense activations into sparse monosemantic features. Ch 10
Self-consistency
Sample N reasoning traces; majority-vote the answer. Ch 03
SGLang
Serving framework. Strong at structured generation and prefix caching. Ch 02
SKILL.md
The file format for a Claude / smolagents skill. YAML frontmatter + instructions + optional scripts. Ch 06
Structured output
Constraining a model to JSON / XML / a Pydantic schema. Ch 03
Sub-agent
A spawned agent with its own context window. Isolates concerns from the main loop. Ch 06, 09
SWE-bench
Benchmark of real GitHub issues. The "Verified" split is the public frontier coding eval. Ch 11

T

τ-bench / τ2-bench
Sierra Research's multi-turn tool-use benchmarks. Ch 11
Temperature
Sampling parameter controlling randomness. 0 = greedy; 0.7-1.0 = creative. Ch 02, 03
Tokenization
Splitting text into tokens via BPE. Source of many LLM quirks. Ch 03 · Vol III Ch 03
Tool use
Model emits a tool-call; runtime executes; result fed back. The agent primitive. Ch 01, 07
Tree of Thoughts
Search pattern for agents: sample K candidate thoughts, evaluate, expand. Ch 08

U

Usage tokens
Input vs. output tokens. Input is cheaper; output dominates cost at long generations. Ch 04, 11

V

Vector store
Database for embeddings (pgvector, Qdrant, LanceDB, Weaviate, ChromaDB). Ch 05
vLLM
Production inference engine. PagedAttention, continuous batching, prefix caching. Ch 02
VRAM
GPU memory. Binding constraint for local model size after quantization. Ch 02
