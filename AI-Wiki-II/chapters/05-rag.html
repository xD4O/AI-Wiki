Retrieval-Augmented Generation

Give a model access to millions of documents without retraining. Embeddings, vector DBs, hybrid search, rerankers, and the 2026 twist: GraphRAG and agentic retrieval.

5.1 Why RAG

A model knows only what was in its training data, and it knows that fuzzily. RAG — retrieval-augmented generation — solves four problems at once:

  • Freshness. Documents from yesterday.
  • Private data. Your internal wiki, medical records, source code.
  • Citations. The model can point at sources the user can verify.
  • Cost. Cheaper than fine-tuning; instantly updatable.
The canonical RAG pipeline. Every RAG variant is a modification of one of these boxes.

5.4 Chunking Strategies

  • Fixed-size (500–1000 tokens, 100-token overlap). Baseline. Works surprisingly well.
  • Sentence / paragraph. Respects natural boundaries; uneven sizes.
  • Semantic chunking (LlamaIndex, LangChain). Embed rolling windows; cut where cosine-sim drops.
  • Sliding hierarchical. Small chunks for retrieval, parent paragraph for context.
  • Contextual retrieval (Anthropic). Prepend a model-generated one-sentence summary to each chunk before embedding — recall jumps meaningfully.

5.5 Hybrid Search & Reranking

Pure vector search is great at semantic matching but bad at exact terms (product codes, names, numbers). BM25 is the opposite. Hybrid search combines them — typically via reciprocal rank fusion (RRF):

$$\text{score}(d) = \sum_{r \in \text{rankers}} \dfrac{1}{k + \text{rank}_r(d)}$$

A reranker (cross-encoder) then reorders the top 50 candidates with a higher-quality but slower model. Typical pipeline: 1000 candidates from ANN → 50 after BM25 fusion → 10 after reranker → 5 into context.

from sentence_transformers import CrossEncoder

reranker = CrossEncoder("BAAI/bge-reranker-v2-m3")
pairs = [(query, doc) for doc in candidates]
scores = reranker.predict(pairs)
top = sorted(zip(candidates, scores), key=lambda x: -x[1])[:10]

5.6 Advanced — HyDE, Multi-Query, GraphRAG, Agentic Retrieval

  • HyDE (Hypothetical Document Embeddings): ask the LLM to hallucinate an answer; embed that; search. The hallucinated answer is closer in embedding space to real answers than the question itself.
  • Multi-query rewriting. Have the LLM expand one query into 3–5 phrasings, search each, fuse.
  • GraphRAG (Microsoft, 2024). Build a knowledge graph from the corpus; retrieve subgraph summaries for global questions ("what are the main themes of this book?").
  • LazyGraphRAG (2025). Defers graph building to query-time — 0.1% of indexing cost with ~95% of quality.
  • Agentic retrieval. Don't do retrieval as a single pre-step. Let the agent call a search() tool mid-loop, read, refine the query, and search again. This is how Claude Code finds things.

5.7 Evaluating RAG

RAGAS and friends measure three things:

  • Faithfulness — is the answer supported by the retrieved passages?
  • Answer relevance — does the answer address the question?
  • Context precision / recall — did retrieval find what mattered, without noise?
from ragas import evaluate
from ragas.metrics import faithfulness, answer_relevancy, context_precision

scores = evaluate(dataset, metrics=[faithfulness, answer_relevancy, context_precision])

5.8 A 60-Line Local RAG

import ollama, lancedb, pyarrow as pa
from lancedb.embeddings import get_registry

db = lancedb.connect("./.rag")
embed = get_registry().get("ollama").create(name="mxbai-embed-large")

# --- ingest ---
docs = [open(p).read() for p in ["docs/a.md", "docs/b.md", "docs/c.md"]]
def chunk(text, size=700, overlap=100):
    for i in range(0, len(text), size - overlap):
        yield text[i:i+size]

rows = [{"text": c, "vector": embed.compute_source_embeddings([c])[0]}
        for d in docs for c in chunk(d)]
tbl = db.create_table("kb", rows, mode="overwrite")
tbl.create_fts_index("text")

# --- query ---
def rag(query, k=4):
    hits = tbl.search(query).limit(k).to_list()  # hybrid: BM25 + vector
    ctx = "\n---\n".join(h["text"] for h in hits)
    prompt = f"Answer using ONLY the context.\n\n{ctx}\n\nQ: {query}\nA:"
    r = ollama.chat(model="qwen2.5:32b", messages=[{"role": "user", "content": prompt}])
    return r["message"]["content"], hits

ans, sources = rag("How do I rotate the master key?")
print(ans)
for s in sources: print("-", s["text"][:80])
