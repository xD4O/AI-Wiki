12.1 Reasoning & Inference-Time Compute

The big shift of 2024–2025 was that quality no longer scales only with training compute — it also scales with inference compute. RL-trained reasoning models (OpenAI's o-series, DeepSeek-R1, Claude extended thinking, Qwen QwQ) spend up to tens of thousands of tokens "thinking" before answering.

Spending tokens at inference is now a first-class quality lever. Cost-per-correct-answer can still win vs. a larger model.

12.2 Computer Use & Browser Agents

In 2024–2025, Anthropic, OpenAI, and Google shipped computer-use modes — models that see screenshots and emit mouse/keyboard actions. In 2026 this moved from demo to real workflows: form-filling in legacy enterprise apps, browser QA, and Claude surfaces inside Chrome, Excel, and PowerPoint.

Browser agents (BrowserBase, Playwright-MCP, OpenAI Operator, Replit) sit alongside — better than pure computer-use for web-scoped tasks because the DOM is richer signal than pixels.

12.3 Native Multimodality

Vision, audio, and video are no longer bolted onto text models; they are trained jointly from scratch. Practical implications:

  • Voice. Realtime speech-to-speech models (GPT-4o-realtime, Gemini Live) remove the STT/TTS pipeline entirely.
  • Vision. Image / PDF / chart understanding is now baseline. Qwen 2.5-VL, Claude vision, Gemini Flash all handle document extraction well enough to replace Tesseract for most tasks.
  • Video. Long-form video understanding (hours) is still the frontier.

12.4 Continual Learning & Persistent Memory

A model's training is frozen, but we can give it a memory that isn't. Libraries like Letta (formerly MemGPT) and mem0 maintain a structured store of facts, preferences, and past interactions, retrieved into each turn.

Recent survey work (arXiv:2512.13564) and position pieces like "Continual Learning, Not Training" argue the next frontier is a model that updates from deployment experience without losing calibration — still an open problem.

12.5 On-Device Models

Apple Intelligence (3B on-device + private-cloud fallback), Qualcomm/MediaTek NPU runtimes, and Google's Gemini Nano have put useful models on every phone. The watershed: a 2–4B model fine-tuned + quantized onto an NPU is now fast enough to do autocomplete, summarization, and transcription without a network round-trip.

12.6 Capstone — Build Your Own Agentic App

A ~300-line reference app that stitches Chapters 2, 4, 5, 7, 8, and 11 into one workflow: a local personal research assistant that reads your Obsidian vault, answers questions with citations, can browse the web when needed, and logs every run.

The capstone: every layer of Volume II in one 300-line program. 
"""Capstone: local personal research assistant (abridged).
Fills the blanks with Ch 2/4/5/7/11 patterns — see /AI-Wiki-II/chapters/.
"""
import os, time, json, pathlib, lancedb, ollama
from openai import OpenAI
from langfuse.decorators import observe

VAULT = pathlib.Path.home() / "obsidian-vault"
DB    = lancedb.connect("./.assistant")

# 1. Nightly ingest: chunk + embed vault notes
def ingest():
    from lancedb.embeddings import get_registry
    em = get_registry().get("ollama").create(name="mxbai-embed-large")
    rows = []
    for md in VAULT.rglob("*.md"):
        text = md.read_text()
        for i in range(0, len(text), 700):
            chunk = text[i:i+800]
            rows.append({"path": str(md), "text": chunk, "vector": em.compute_source_embeddings([chunk])[0]})
    DB.create_table("vault", rows, mode="overwrite").create_fts_index("text")

# 2. Agent loop with prompt caching, rolling summary, budget cap
client = OpenAI(base_url="http://localhost:11434/v1", api_key="ollama")
TOOLS = load_mcp_tools(["obsidian", "web"])   # see Ch 07 for registration

SYSTEM = """You are Duy's research assistant. Always cite the vault note by path.
If the vault doesn't contain the answer, use web.fetch. Keep answers under 400 words."""

@observe()  # Langfuse trace wrapper
def assistant(question, max_steps=10, budget_usd=0.50):
    spent, history = 0.0, [{"role": "system", "content": SYSTEM}, {"role": "user", "content": question}]
    for step in range(max_steps):
        r = client.chat.completions.create(
            model="qwen2.5:32b", messages=history, tools=TOOLS,
            extra_body={"cache_control": {"type": "ephemeral"}},
        )
        spent += estimate_cost(r.usage)
        if spent > budget_usd:
            return "(budget exceeded)"
        msg = r.choices[0].message
        history.append(msg.model_dump())
        if not msg.tool_calls:
            return msg.content
        for call in msg.tool_calls:
            result = run_mcp_tool(call.function.name, json.loads(call.function.arguments))
            history.append({"role": "tool", "tool_call_id": call.id, "content": result})

if __name__ == "__main__":
    if "--ingest" in os.sys.argv: ingest()
    else: print(assistant(" ".join(os.sys.argv[1:])))

Run it:

python assistant.py --ingest          # build the index
python assistant.py "what did I decide about the quarterly planning doc?"
Now extend it

Swap in a cloud frontier model when a local router classifies the question as "hard." Add a planner subagent (Ch 09) for multi-vault research tasks. Wire up a prompt-injection eval suite (Ch 11) so you know when the web fetcher gets poisoned. The wiki is a map — the territory is up to you.

12.7 Signals to Watch

  • Benchmark migration. When the field abandons a benchmark (SWE-bench Verified) it's because the frontier broke through it. Watch what replaces it — that's the new ceiling.
  • Open-weight gap. Every year the delta between the best closed and best open model shrinks. Track it on LMSYS Arena.
  • Inference-compute curves. When a small model + big thinking budget beats a bigger model, that changes product economics.
  • On-device capability. When a 4B model genuinely replaces a 70B for your task, your architecture changes.
  • MCP adoption. Number of first-party MCP servers published by SaaS vendors. When Salesforce / Workday / Oracle ship one, the "agent operating system" layer has arrived.
