The Curriculum

Twelve chapters in four parts, each building on the previous. Prerequisites: Volume I or equivalent knowledge of transformers, training, and alignment.

Part I · Using Models

Chapter 01

From Chatbot to Agent

The agency spectrum, the agent loop, and when a tool-calling LLM becomes an "agent."
Chapter 02

Local Models

Run 70B models on your own hardware — Ollama, LM Studio, GGUF, vLLM, MLX.
Chapter 03

The Art of Prompting

Principled prompt design — structured output, few-shot, reasoning models, anti-patterns.

Part II · Context & Memory

Chapter 04

Context Engineering

Engineer the context window — caching, compaction, lost-in-the-middle, token economy.
Chapter 05

Retrieval-Augmented Generation

Embeddings, vector DBs, hybrid search, rerankers, GraphRAG, and RAG evaluation.
Chapter 06

Skills & Reusable Prompts

SKILL.md, skill composition, and turning capabilities into org-wide assets.

Part III · Agents

Chapter 07

MCP — Model Context Protocol

The open standard for plugging tools and data into any model. Servers, clients, security.
Chapter 08

Agent Architectures

ReAct, plan-execute, Reflexion, tree-of-thought — when to use what.
Chapter 09

Multi-Agent Systems

Orchestrator-worker, debate, ensembles — when a team beats a single model.

Part IV · Production

Chapter 10

Interpretability

SAEs, circuits, steering vectors — what's actually happening inside the model.
Chapter 11

Evals, Safety & Ops

SWE-bench, τ-bench, tracing, guardrails, cost management, and observability.
Chapter 12

Frontier 2026 & Capstone

Reasoning models, computer use, continual memory — and a ~300-line capstone app.

How Volume II Differs

🛠 Practitioner-first

Vol I taught theory. Vol II teaches deployment. Every chapter ends with runnable code.

🏠 Local by default

Most examples run on your own hardware via Ollama or LM Studio. No API key required.

🔗 Resource-dense

Every chapter ships with verified 2026 links: papers, HF models, blogs, benchmarks, accounts.

Assumes Volume I

We don't re-derive attention or explain gradient descent. If something is unfamiliar, jump back to Volume I.
